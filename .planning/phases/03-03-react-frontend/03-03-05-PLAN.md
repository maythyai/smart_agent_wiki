<action>
Create `web/src/hooks/usePage.ts`:

1. `usePage(slug: string)` hook:
   - `useQuery` with queryKey `['page', slug]`
   - Fetch from `/api/pages/${slug}` via api client
   - Enable only when `slug` is truthy
   - Return `{ data, isLoading, error }`

2. `useUpdatePage(slug: string)` hook:
   - `useMutation` for PUT to `/api/pages/${slug}`
   - On success, invalidate `['page', slug]`
   - Return `{ mutate: updatePage, isPending }`

3. `useDeletePage(slug: string)` hook:
   - `useMutation` for DELETE to `/api/pages/${slug}`
   - On success, navigate to `/`
   - Return `{ mutate: deletePage, isPending }`

Export all three hooks.
</action>

## Task 2: Create useWebSocket Hook

<read_first>
- web/src/stores/dashboardStore.ts
- web/src/types/websocket.ts
</read_first>

<action>
Create `web/src/hooks/useWebSocket.ts`:

1. Accept optional `sessionId?: string`

2. Get `setConnectionStatus`, `updateAgent`, `updateWorkflow` from Zustand store

3. Get `useQueryClient` for cache invalidation

4. `connect` callback:
   - Create WebSocket to `ws://localhost:8000/ws` (or `VITE_WS_URL` env)
   - `onopen`: set status 'connected', reset reconnect attempts, refetch agents
   - `onclose`: set status 'disconnected', schedule reconnect with exponential backoff (1s, 2s, 4s... max 30s) per D-21
   - `onmessage`: parse JSON, route by type:
     - `agent_status`: call `updateAgent`, invalidate `['agents']`
     - `workflow_progress`: call `updateWorkflow`, invalidate `['agents']`
     - `page_updated`: invalidate `['page', slug]` and `['graph']`

5. Heartbeat (per D-22: 30s interval):
   - Send `{ type: 'ping' }` every 30 seconds when connected
   - Clear interval on disconnect and unmount

6. Return `{ status, send, reconnect }`

7. Handle cleanup in `useEffect` return
</action>
