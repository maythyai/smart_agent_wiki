# Plan 04-01: Media Extractor Core

**Objective:** 实现 MediaExtractor 类，支持视频/音频文件上传和 Whisper 转录

## Context

Phase 4 的核心是实现媒体文件转录功能。本计划覆盖 MediaExtractor 核心类实现，包括：
- 视频格式支持 (MP4, WebM, MOV)
- 音频格式支持 (MP3, WAV, M4A, OGG)
- Whisper 本地/API 双模式
- 元数据提取

## truths

- 使用 faster-whisper 而不是官方 whisper（性能优化）
- 懒加载 Whisper 模型（节省内存）
- 临时文件必须清理（防止磁盘泄漏）
- GPU 不可用时自动降级到 CPU
- 文件大小限制 500MB（防止内存溢出）
