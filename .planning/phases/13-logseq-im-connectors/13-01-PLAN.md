# Reference: Existing Connector Patterns (Phase 10-12)

## UnifiedConnectorInterface Protocol (from Phase 10-01)
```python
class UnifiedConnectorInterface(Protocol):
    platform_name: str
    supports_push: bool

    async def authenticate(self, config: dict) -> AuthResult: ...
    async def get_items(self, since: datetime | None = None) -> list[ConnectorItem]: ...
    async def put_item(self, item: ConnectorItem) -> ConnectorItem: ...
    async def delete_item(self, item_id: str) -> bool: ...
    def transform_to_claim(self, item: ConnectorItem) -> Claim: ...
    def transform_from_claim(self, claim: Claim) -> ConnectorItem: ...
```

## SyncEngine Integration (from Phase 11-01)
- `SyncEngine.pull(connector_id)` - calls `get_items()` and transforms to Claims
- `SyncEngine.push(connector_id)` - calls `put_item()` for pending writes
- Loop prevention via `source_platform` in Claim metadata

## BaseConnector (from Phase 10-01)
```python
class BaseConnector:
    def __init__(self, config: ConnectorConfig, rate_limiter: RateLimitManager):
        self.config = config
        self.rate_limiter = rate_limiter

    async def _check_rate_limit(self) -> None:
        await self.rate_limiter.acquire(self.platform_name)
```
