Create comprehensive Notion block to markdown converter.

1. Create `src/saw/connectors/notion/blocks.py`:

   - `RichTextRenderer` class:
     - `render_rich_text(rich_text: list[dict]) -> str`:
       - Iterate through rich_text items
       - Handle annotations: bold (**text**), italic (*text*), code (`text`), strikethrough (~~text~~), underline, color
       - Handle types: text, mention (user/page/database/date), equation
       - Mention: `[@User Name]` or `[Page Title](notion://page_id)`
       - Return concatenated plain text with markdown formatting

   - `BlockRenderer` class:
     - `__init__(client: AsyncClient)`:
       - Store client for fetching block children (nested blocks)

     - `async def render_block(block: dict) -> str`:
       - Dispatch to specific handler based on block.type
       - Handle unknown types gracefully with placeholder

     - `async def render_blocks_to_markdown(blocks: list[dict], indent: int = 0) -> str`:
       - Render list of blocks to markdown string
       - Recursively fetch and render children for blocks with has_children=True
       - Apply indentation for nested content
       - Join with newlines

   - Block handlers (all async):
     - `_render_paragraph(block)`: Extract rich_text, render with RichTextRenderer
     - `_render_heading(block, level: int)`: `{"#" * level} {text}\n`
     - `_render_bulleted_list_item(block)`: `- {text}\n`
     - `_render_numbered_list_item(block, number: int)`: `{number}. {text}\n`
     - `_render_to_do(block)`: `- [{'x' if checked else ' '}] {text}\n`
     - `_render_code(block)`: Fenced code block with language
       ```markdown
       ```{language}
       {code_text}
       ```
       ```
     - `_render_quote(block)`: `> {text}\n` (handle multi-line)
     - `_render_divider(block)`: `---\n`
     - `_render_callout(block)`: Blockquote with emoji icon
       ```markdown
       > {icon} {text}
       ```
     - `_render_image(block)`: `![alt](url)` or caption handling
     - `_render_video(block)`: `[Video: {url}]` or embed placeholder
     - `_render_file(block)`: `[File: {name}]({url})`
     - `_render_bookmark(block)`: `[{title}]({url})`
     - `_render_equation(block)`: `$$\n{expression}\n$$`
     - `_render_toggle(block)`: `<details><summary>{text}</summary>\n{children}</details>`
     - `_render_column_list(block)`: Render children flattened (column layout not preserved)
     - `_render_column(block)`: Render children
     - `_render_table(block)`: Markdown table with rows
     - `_render_table_row(block)`: `| cell1 | cell2 |`
     - `_render_synced_block(block)`: Render as regular content
     - `_render_template(block)`: Placeholder for button/template blocks
     - `_render_link_to_page(block)`: Link to page
     - `_render_child_page(block)`: Nested page reference
     - `_render_child_database(block)`: Database reference
     - `_render_unknown(block)`: `<!-- Unknown block type: {type} -->`

   - Helper functions:
     - `extract_plain_text(rich_text: list[dict]) -> str`: Plain text without formatting
     - `get_block_children(block_id: str) -> list[dict]`: Fetch children via API

2. Integration with NotionTransformer:
   - Fetch page content blocks via `client.blocks.children.list(block_id=page_id)`
   - Paginate through all blocks
   - Pass to `render_blocks_to_markdown()` for conversion
   - Result becomes Claim.content

SDK usage for blocks:
```python
blocks = []
has_more = True
start_cursor = None
while has_more:
    response = await client.blocks.children.list(
        block_id=page_id,
        start_cursor=start_cursor,
    )
    blocks.extend(response["results"])
    has_more = response["has_more"]
    start_cursor = response.get("next_cursor")
```
