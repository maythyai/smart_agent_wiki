<!-- Conflict detection criteria from NOTI-06 -->
Concurrent edit detected when:
1. Both Notion page AND SAW Claim modified after last_sync_at
2. last_edited_time (Notion) > last_sync_at AND updated_at (SAW) > last_sync_at

Resolution (NOTI-06):
- Compare last_edited_time vs updated_at timestamps
- Later timestamp wins (last-modified-wins)
- Log conflict with both versions for manual review

     - `async def detect(page: NotionPage, claim: dict, last_sync_at: datetime) -> NotionConflictInfo | None`:
       - Compare timestamps:
         ```python
         notion_modified = page.last_edited_time > last_sync_at
         saw_modified = datetime.fromisoformat(claim["updated_at"]) > last_sync_at
         
         if notion_modified and saw_modified:
             return NotionConflictInfo(...)
         return None
         ```
       - Normalize all timestamps to UTC before comparison

     - `async def resolve(conflict: NotionConflictInfo) -> ConflictResolution`:
       - Apply strategy:
         ```python
         if self._strategy == ConflictStrategy.LAST_MODIFIED_WINS:
             if conflict.notion_edited_time >= conflict.saw_updated_time:
                 winner = "notion"
             else:
                 winner = "saw"
         elif self._strategy == ConflictStrategy.PLATFORM_WINS:
             winner = "notion"
         elif self._strategy == ConflictStrategy.SAW_WINS:
             winner = "saw"
         # MANUAL strategy: mark for human review, don't auto-resolve
         ```
       - Generate conflict_id for tracking

     - `async def log_conflict(conflict: NotionConflictInfo, resolution: ConflictResolution) -> str`:
       - Insert into ConflictRecordModel:
         ```python
         record = ConflictRecordModel(
             connector_id=...,
             source_platform="notion",
             source_id=conflict.page_id,
             conflict_type="concurrent_edit",
             platform_version={
                 "title": conflict.notion_title,
                 "content": conflict.notion_content_preview,
                 "edited_time": conflict.notion_edited_time.isoformat(),
             },
             saw_version={
                 "title": conflict.saw_title,
                 "content": conflict.saw_content_preview,
                 "updated_time": conflict.saw_updated_time.isoformat(),
             },
             resolution={
                 "winner": resolution.winner,
                 "reason": resolution.reason,
             },
             resolved_at=datetime.now(timezone.utc),
         )
         ```
       - Return conflict_id for reference

   - `async def get_unresolved_conflicts() -> list[ConflictRecordModel]`:
     - Query for conflicts where resolution == "manual" or not yet resolved
     - Return for admin review

2. Integration considerations:

   - Notion API returns ISO 8601 with timezone
   - SAW Claims use UTC internally
   - Convert to UTC before comparison if needed
