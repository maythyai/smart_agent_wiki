<task type="auto">
  <name>Task 2: Create Settings API endpoints</name>
  <files>src/saw/api/connector_settings.py, src/saw/api/__init__.py</files>
  <action>
Create FastAPI router for connector settings per D-04, D-05, D-06.

Endpoints:
1. GET /api/v1/connectors/{platform}/settings (D-04)
   - Returns current settings for platform
   - Returns default values if no settings exist yet
   - Response: SettingsResponse with sync_interval, sync_directions, property_mappings, rate_limit_override

2. PUT /api/v1/connectors/{platform}/settings (D-05)
   - Updates settings for platform
   - Validates sync_interval against allowed values per D-07
   - Validates sync_directions against allowed values per D-09-D-11
   - Rate limit override must be within safety bounds (CONF-05)
   - Returns updated settings confirming save

3. POST /api/v1/connectors/{platform}/reauth (D-06)
   - Returns OAuth re-authorization URL
   - Delegates to existing OAuth handler in connector

Pydantic models:
- SettingsResponse: sync_interval, sync_directions, property_mappings, rate_limit_override, updated_at
- SettingsUpdateRequest: sync_interval (optional), sync_directions (optional), property_mappings (optional), rate_limit_override (optional)
- ReauthResponse: authorize_url, state (reuse from integrations.py)

Validation:
- sync_interval must be one of: "5min", "15min", "1hr", "6hr", "manual"
- sync_directions must be one of: "inbound_only", "outbound_only", "bidirectional"
- rate_limit_override must be >= 1 and <= 100 (safety bounds)

Register router in src/saw/api/__init__.py.
