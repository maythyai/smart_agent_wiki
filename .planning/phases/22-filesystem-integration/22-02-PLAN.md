<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Watched Folder → App | External files appear in watched folder, app processes them |
| App → Export Location | App writes exported content to user-selected location |
| IPC Events | Rust emits file events to JavaScript frontend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-05 | Tampering | Watched folder content | mitigate | Validate file types before ingestion, reject unsupported formats |
| T-22-06 | Information Disclosure | Export content | accept | User explicitly initiates export, content is their own data |
| T-22-07 | Denial of Service | Folder watcher | mitigate | Debounce rapid events, limit number of watched folders |
| T-22-08 | Spoofing | File events | mitigate | Include full path in events, frontend validates before action |

</threat_model>
