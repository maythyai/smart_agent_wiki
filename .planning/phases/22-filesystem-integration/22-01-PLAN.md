<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebView → Rust IPC | JavaScript invokes Rust commands for file operations |
| File System | App has scoped access to user files via tauri-plugin-fs |
| User Data | App data stored in platform-standard location |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-01 | Spoofing | Drag-drop paths | mitigate | Validate paths are from actual file system, not crafted strings |
| T-22-02 | Tampering | App data files | accept | User controls app data directory; no secrets stored |
| T-22-03 | Information Disclosure | File contents | mitigate | Only ingest files user explicitly selects |
| T-22-04 | Elevation of Privilege | fs scope | mitigate | Dynamic scope only for user-selected paths via dialog |

</threat_model>
