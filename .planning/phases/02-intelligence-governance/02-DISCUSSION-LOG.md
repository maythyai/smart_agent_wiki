## 置信度计算

### Q1: Wiki 页面置信度如何升级？

| Option | Description | Selected |
|--------|-------------|----------|
| 自动升级 | 当同一主张被 2+ 独立来源提取时自动升级到 Cross-Validated。定义明确、可自动化。 | |
| 人工审核后升级 | 任何置信度升级都需要人工审核确认。更可靠但增加用户负担。 | |
| 混合模式 | Cross-Validated 以下自动升级，Human Verified 需要人工审核。平衡自动化与控制。 | ✓ |

**User's choice:** 混合模式
**Notes:** 无

---

### Q2: 主张级来源标记设计？

| Option | Description | Selected |
|--------|-------------|----------|
| 三等级正交（设计文档） | extracted=直接从文档提取、inferred=通过推理得出、ambiguous=无法确定来源类型。主张级标记与页面置信度正交组合。 | ✓ |
| 两等级简化 | 简化为 extracted 和 inferred 两级，ambiguous 合入 inferred。减少复杂度。 | |

**User's choice:** 三等级正交（设计文档）
**Notes:** 无

---

### Q3: 置信度是否可以降级？

| Option | Description | Selected |
|--------|-------------|----------|
| 永不自动降级（推荐） | 一旦达到某个置信度就保持，只有通过人工操作可以降级。简单、可预测。 | ✓ |
| 新鲜度触发降级 | 当声称新鲜度过期或被反驳时自动降级。更动态但可能意外。 | |
| 不支持降级 | 不实现降级机制——置信度只升不降。 | |

**User's choice:** 永不自动降级（推荐）
**Notes:** 无

---

### Q4: 升级到 Cross-Validated 需要多少独立来源？

| Option | Description | Selected |
|--------|-------------|----------|
| 2 个来源（推荐） | 最少 2 个独立来源确认即升级。平衡可靠性与可达性。 | ✓ |
| 3 个来源 | 需要 3+ 独立来源，更严格但难以达到。适合高精度场景。 | |
| 可配置阈值 | 用户在配置中设定阈值，默认 2。灵活但增加复杂度。 | |

**User's choice:** 2 个来源（推荐）
**Notes:** 无

## 矛盾检测算法

### Q6: 矛盾检测何时执行？

| Option | Description | Selected |
|--------|-------------|----------|
| 实时检测 | 每次摄入新声称时实时检测。即时反馈但可能影响性能。 | |
| 批量检测 | 用户运行 `saw lint` 或 `saw conflicts` 时检测。可控、不影响摄入性能。 | |
| 异步队列 | 后台队列异步检测。平衡实时性和性能，但更复杂。 | ✓ |

**User's choice:** 异步队列
**Notes:** 无

---

### Q7: 矛盾检测的核心算法？

| Option | Description | Selected |
|--------|-------------|----------|
| LLM 语义判断 | 使用 LLM 判断两个声称是否矛盾。语义理解强但耗 API 成本。 | |
| 两阶段（筛选+LLM）（推荐） | 先基于关键词和语义相似度筛选候选，再用 LLM 精确判断。平衡成本与效果。 | ✓ |
| 纯规则检测 | 基于时间戳、数值差异、关键词冲突等规则检测。零 API 成本但可能漏检。 | |

**User's choice:** 两阶段（筛选+LLM）（推荐）
**Notes:** 无

---

### Q8: 矛盾类型分类？

| Option | Description | Selected |
|--------|-------------|----------|
| 三类一致（推荐） | 时间矛盾(更新)、观点矛盾(不同立场)、事实矛盾(无法调和)。覆盖全面。 | |
| 两类简化 | 只区分时间矛盾和内容矛盾两类。简化处理。 | |
| LLM 自动分类 | 由 LLM 自动分类矛盾类型。更智能但可能不一致。 | ✓ |

**User's choice:** LLM 自动分类
**Notes:** 无

---

### Q9: 矛盾解决策略？

| Option | Description | Selected |
|--------|-------------|----------|
