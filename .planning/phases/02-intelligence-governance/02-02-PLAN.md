## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM → Contradiction Classification | External LLM determines contradiction type - untrusted output |
| User → Audit Export | User can export receipts for verification |
| Storage → Receipt Chain | Receipts stored on disk - potential tampering target |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Tampering | Receipt chain | mitigate | Ed25519 signatures detect any modification; chain linking prevents insertion |
| T-02-07 | Spoofing | Agent identity | mitigate | Agent identity included in signed receipt; cannot be forged |
| T-02-08 | Repudiation | All operations | mitigate | Every operation produces signed receipt; non-repudiable |
| T-02-09 | Information Disclosure | Private key | mitigate | Key stored with 0600 permissions; recommend OS keychain |
| T-02-10 | Elevation of Privilege | LLM classification | accept | LLM could misclassify contradiction type, but resolution still applied per rules; human can override |
</threat_model>
