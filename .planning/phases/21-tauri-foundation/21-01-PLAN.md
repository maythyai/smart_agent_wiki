<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebView → Rust IPC | JavaScript code in WebView can invoke Rust commands via @tauri-apps/api |
| File System | Application has access to user files via tauri-plugin-fs |
| Network | Application loads frontend from local files; API calls proxy to localhost:8000 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01 | Spoofing | WebView content | mitigate | Load only from bundled frontendDist, not arbitrary URLs |
| T-21-02 | Tampering | IPC commands | mitigate | Validate all inputs in Rust command handlers with serde |
| T-21-03 | Information Disclosure | Bundle contents | accept | No secrets in bundle; user data stored in app directory |
| T-21-04 | Elevation of Privilege | File system access | mitigate | Use tauri-plugin-fs with explicit scope in capabilities |
</threat_model>
