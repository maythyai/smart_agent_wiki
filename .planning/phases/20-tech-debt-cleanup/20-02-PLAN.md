# Plan 20-02: Vitest Setup and Frontend Tests

**Objective:** Configure Vitest for React frontend and add basic tests for IntegrationCard and IntegrationList components.

---

## Context

The frontend currently lacks test infrastructure. This plan adds Vitest configuration and basic component tests for the integration dashboard components.

---

## Tasks

### Task 1: Install Vitest and Testing Dependencies

**Goal:** Add Vitest and testing utilities to web project

**Command:**
```bash
cd web && npm install -D vitest @testing-library/react @testing-library/jest-dom jsdom @vitest/ui
```

**File to modify:** `web/package.json` (add test scripts)

---

### Task 2: Configure Vitest

**Goal:** Set up Vitest configuration for React Testing Library

**File to create:** `web/vite.config.ts` (update with test config)

**Content:**
```typescript
/// <reference types="vitest" />
import { defineConfig } from 'vitest/config'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  test: {
    globals: true,
    environment: 'jsdom',
    setupFiles: './src/setupTests.ts',
    include: ['src/**/__tests__/**/*.test.{ts,tsx}'],
    coverage: {
      reporter: ['text', 'json', 'html'],
      exclude: ['node_modules/', 'src/setupTests.ts']
    }
  }
})
```
