# Plan 20-03: Bundle Analysis and Optimization

**Objective:** Generate bundle analysis report and implement lazy loading for Milkdown if needed.

---

## Context

The React frontend bundle should be analyzed to identify optimization opportunities. Milkdown is a potential large dependency that may benefit from lazy loading.

---

## Tasks

### Task 1: Install Bundle Analysis Plugin

**Goal:** Add rollup-plugin-visualizer for bundle analysis

**Command:**
```bash
cd web && npm install -D rollup-plugin-visualizer
```

---

### Task 2: Configure Bundle Analysis

**Goal:** Update vite.config.ts with bundle analysis plugin

**File to modify:** `web/vite.config.ts`

**Add to plugins:**
```typescript
import { visualizer } from 'rollup-plugin-visualizer'

// In plugins array:
visualizer({
  open: false,
  gzipSize: true,
  brotliSize: true,
  filename: '../.planning/bundle-analysis/stats.html'
})
```

---

### Task 3: Run Build and Generate Report

**Goal:** Build frontend and generate bundle analysis

**Command:**
```bash
cd web && npm run build
```

**Output:** `.planning/bundle-analysis/stats.html`

**Analysis:**
- Identify largest dependencies
- Check Milkdown size impact
- Document findings in `.planning/bundle-analysis/report.md`

---

### Task 4: Evaluate and Implement Milkdown Lazy Loading

**Goal:** Lazy load Milkdown editor if bundle size > 100KB

**Decision criteria:**
- If Milkdown + dependencies < 100KB: No action needed
- If Milkdown + dependencies > 100KB: Implement lazy loading

**Implementation (if needed):**

**File to modify:** `web/src/components/editor/MilkdownEditor.tsx`

```typescript
import { lazy, Suspense } from 'react'

const MilkdownEditorLazy = lazy(() => import('./MilkdownEditorInner'))

export function MilkdownEditor(props: Props) {
  return (
    <Suspense fallback={<div>Loading editor...</div>}>
      <MilkdownEditorLazy {...props} />
    </Suspense>
  )
}
```

---

## Success Criteria

1. Bundle analysis report generated
2. Report documents total bundle size and largest dependencies
3. Milkdown lazy loading decision documented
4. If implemented, lazy loading works correctly
