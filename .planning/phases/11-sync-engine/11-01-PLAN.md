  <action>
    Create the core SyncEngine that orchestrates bidirectional sync.

    Create `src/saw/connectors/sync_engine.py`:

    1. Define enums and dataclasses:
       - `SyncMode` enum: `FULL`, `INCREMENTAL`
       - `SyncOptions` dataclass:
         - `direction: SyncDirection = SyncDirection.BIDIRECTIONAL`
         - `mode: SyncMode = SyncMode.INCREMENTAL`
         - `force: bool = False` (ignore last_sync_at)

    2. `SyncEngine` class:
       - `__init__(self, registry: ConnectorRegistry, write_queue: WriteQueue, session: AsyncSession)`
       - Dependencies: `SyncStatusTracker`, `SyncLogger`, `ConflictResolver`

       - `async def sync(self, connector_id: str, options: SyncOptions | None = None) -> SyncResult`
         - Orchestrates pull and/or push based on direction

       - `async def sync_pull(self, connector: UnifiedConnectorInterface, options: SyncOptions) -> SyncResult`
         - Check backpressure: if queue depth > 1000, return with items_skipped
         - Get items since last_sync_at (or all if FULL mode)
         - For each item:
           - Check sync loop: skip if item.metadata.get("source_platform") == connector.platform_name
           - Transform to Claim with metadata: source_platform, source_id, source_url
           - Check for conflicts with existing Claims
           - Queue write to WriteQueue
         - Log via SyncLogger
         - Update SyncStatus

       - `async def sync_push(self, connector: UnifiedConnectorInterface, options: SyncOptions) -> SyncResult`
         - Only for connectors with supports_push=True
         - Find Claims modified since last_sync_at
         - Skip Claims where source_platform == connector.platform_name (loop prevention)
         - Transform from Claim to ConnectorItem
         - Call connector.put_item()
         - Log via SyncLogger

       - `async def check_backpressure(self) -> tuple[bool, int]`
         - Returns (should_pause, current_depth)
         - Pause when depth > 1000
         - Resume when depth < 500 (hysteresis)

       - `def _is_sync_loop(self, item: ConnectorItem, target_platform: str) -> bool`
         - Returns True if item.metadata.get("source_platform") == target_platform

       - `def _create_claim_from_item(self, item: ConnectorItem, platform: str) -> ClaimCreate`
         - Sets metadata with source_platform, source_id, source_url
         - Sets thread_parent_id if present in item.metadata

    3. Integration with WriteQueue:
       - Import from `src/saw/write_queue/queue.py`
       - Use `write_queue.enqueue()` for Claim creation
       - Monitor `write_queue.depth()` for backpressure

    Per SYNC-02: source_platform/source_id tracking prevents sync loops.
    Per SYNC-05: Backpressure handling via Write Queue depth monitoring.
    Per ERRO-04: All operations wrapped in try/except with error logging.
