### Task 2: Implement rate limiter throughput benchmark

**type:** auto

**behavior:**
- Create benchmark test that sends 1000 requests at 10x configured rate
- Measure allowed vs throttled requests
- Verify throttling correctly limits to configured rate

**implementation:**
```python
# tests/benchmarks/test_rate_limiter_benchmark.py
import asyncio
import pytest
from saw.connectors.rate_limiter import RateLimitManager, PlatformRateLimit

class TestRateLimiterBenchmark:
    @pytest.mark.asyncio
    async def test_throughput_under_10x_load(self, benchmark):
        """PERF-01: Verify throttling under 10x load."""
        limiter = RateLimitManager("notion")  # 3 req/s

        async def make_requests(n: int):
            allowed = 0
            throttled = 0
            for _ in range(n):
                start_tokens = limiter._tokens
                await limiter.acquire()
                if limiter._tokens < start_tokens:
                    allowed += 1
                else:
                    throttled += 1
            return allowed, throttled

        # Run 100 requests (should take ~33s at 3 req/s)
        allowed, throttled = await make_requests(100)
        # Verify rate limiting occurred
```

**done when:**
- Benchmark test file created
- Test measures throughput under 10x load

### Task 4: Implement latency distribution benchmark

**type:** auto

**behavior:**
- Measure latency for acquire() calls under various loads
- Calculate p50, p90, p99 latencies
- Generate latency distribution report

**implementation:**
```python
@pytest.mark.asyncio
async def test_latency_distribution(self, benchmark_dir):
    """PERF-03: Document latency distribution."""
    import time

    limiter = RateLimitManager("notion")
    latencies = []

    for _ in range(100):
        start = time.perf_counter()
        await limiter.acquire()
        end = time.perf_counter()
        latencies.append((end - start) * 1000)  # ms

    p50 = sorted(latencies)[50]
    p90 = sorted(latencies)[90]
    p99 = sorted(latencies)[99]

    report = {
        "benchmark": "rate_limiter_latency",
        "results": {
            "p50_ms": p50,
            "p90_ms": p90,
            "p99_ms": p99,
        }
    }
```
