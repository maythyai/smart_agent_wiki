```python
class BaseConnector:
    def __init__(self, config: ConnectorConfig, rate_limiter: RateLimitManager):
        self._config = config
        self._rate_limiter = rate_limiter

    async def _with_rate_limit(self, operation: Callable) -> Any:
        await self._rate_limiter.acquire(self.platform_name)
        return await operation()
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → OAuth | User authorizes SAW to access GitHub data |
| SAW → GitHub API | SAW makes authenticated requests to GitHub |
| GitHub → SAW OAuth | GitHub redirects with authorization code |
| GitHub → SAW Webhook | GitHub sends webhook events (Plan 14-03) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Spoofing | OAuth callback | mitigate | Validate state parameter matches stored OAuth state (15-min TTL) |
| T-14-02 | Tampering | Sync cursor | mitigate | Cursor stored server-side with user_id FK, not client-controlled |
| T-14-03 | Information Disclosure | OAuth tokens | mitigate | Tokens encrypted at rest via Fernet (Phase 10-02) |
| T-14-04 | Information Disclosure | API responses | mitigate | Tokens masked in logs/responses showing last 4 chars only (AUTH-04) |
| T-14-05 | Denial of Service | Rate limiting | accept | GitHub enforces 5000 req/hr; SAW respects via RateLimitManager |
| T-14-06 | Elevation of Privilege | Repository access | mitigate | Only query repos user has explicit access; OAuth/App scopes are minimal |
| T-14-07 | Spoofing | GitHub App installation | mitigate | Validate installation_id belongs to our App via API verification |
</threat_model>
