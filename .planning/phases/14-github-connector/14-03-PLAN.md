class WebhookVerifier:
    @staticmethod
    async def verify_github_signature(payload: bytes, signature: str, secret: str) -> bool:
        # HMAC-SHA256 verification
        expected = "sha256=" + hmac.new(secret, payload, sha256).hexdigest()
        return hmac.compare_digest(signature, expected)

<!-- GitHub webhook event types -->
GitHub Webhook Event Types:
- issues: opened, edited, closed, reopened, labeled, unlabeled
- issue_comment: created, edited, deleted
- discussion: created, edited, closed, reopened, answered, unanswered
- discussion_comment: created, edited, deleted

<!-- Webhook payload structure -->
Webhook Headers:
- X-GitHub-Event: Event type (issues, issue_comment, etc.)
- X-GitHub-Delivery: Unique delivery ID (UUID)
- X-Hub-Signature-256: HMAC-SHA256 signature
- X-GitHub-Hook-ID: Hook ID that triggered the event

Webhook Payload (common fields):
```json
{
  "action": "opened",
  "issue": { /* Issue object */ },
  "repository": { "id": 123, "full_name": "owner/repo" },
  "sender": { "login": "username" }
}
```

   - `POST /api/v1/webhooks/github`:
     ```python
     @router.post("/webhooks/github")
     async def handle_github_webhook(
         request: Request,
         session: AsyncSession = Depends(get_session)
     ):
         # 1. Get raw body
         payload_bytes = await request.body()
         payload = json.loads(payload_bytes)

         # 2. Verify signature
         signature = request.headers.get("X-Hub-Signature-256", "")
         if not await handler.verify_signature(payload_bytes, signature):
             raise HTTPException(401, "Invalid webhook signature")

         # 3. Parse event
         event = await handler.parse_event(dict(request.headers), payload)

         # 4. Check for duplicate
         if await handler.is_duplicate_delivery(event.delivery_id):
             return {"status": "duplicate_ignored"}

         # 5. Check repository selection
         if not await handler.is_repository_selected(event.repository):
             return {"status": "repository_not_selected"}

         # 6. Process event
         items = await handler.process_event(event)

         # 7. Return response
         return {"status": "processed", "items_count": len(items)}
     ```
