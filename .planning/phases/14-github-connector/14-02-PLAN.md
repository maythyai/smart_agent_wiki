Implement IssueFetcher with conditional requests and pagination for efficient GitHub REST API usage.

1. Create `src/saw/connectors/github/issue_fetcher.py`:
   - `IssueFetcher` class:
     - `__init__(client: Github, session: AsyncSession, connector_id: str, rate_limiter: RateLimitManager)`

     - `async def fetch_issues(repository: str, since: datetime | None = None, cursor: GitHubSyncCursorModel | None = None) -> tuple[list[GitHubIssue], str | None, bool]`:
       - Build query with filters:
         - state: "all" (include closed issues)
         - since: datetime (for incremental sync)
         - sort: "updated"
         - direction: "desc"
       - Conditional request:
         - If cursor.etag exists, add header: `If-None-Match: cursor.etag`
         - If response is 304, return ([], None, False) indicating no changes
         - On 200, capture new ETag from response header
       - Use PyGithub's PaginatedList for automatic pagination:
         ```python
         issues = repo.get_issues(state='all', since=since_dt, sort='updated', direction='desc')
         for issue in issues:
             # PyGithub handles pagination automatically
         ```
       - Track rate limit from response headers:
         - X-RateLimit-Remaining
         - X-RateLimit-Reset
       - Return tuple: (issues, new_etag, has_more)

     - `async def fetch_issue_comments(repository: str, issue_number: int) -> list[GitHubComment]`:
       - GET /repos/{owner}/{repo}/issues/{issue_number}/comments
       - Transform to GitHubComment list
       - Paginate through all comments

     - `async def fetch_all_issues_with_comments(repository: str, since: datetime | None = None, cursor: GitHubSyncCursorModel | None = None) -> tuple[list[GitHubIssue], list[GitHubComment], str | None]`:
       - Fetch issues using fetch_issues()
       - For each issue with comments_count > 0, fetch comments
       - Rate limit: space out comment fetches (not all at once)
       - Return combined results with new ETag

     - `def parse_link_header(link_header: str) -> dict[str, str]`:
       - Parse GitHub's Link header for pagination
       - Extract next, last, first, prev URLs
       - Return dict mapping rel to URL

     - `async def update_cursor(cursor: GitHubSyncCursorModel, etag: str | None, last_issue_number: int) -> None`:
       - Update etag, last_issue_number, last_sync_at
       - Commit to database

2. Rate limit handling:
   - Before each API call, check remaining requests
   - If approaching limit (< 100 remaining), implement adaptive slowdown
   - Store rate limit state in GitHubRateLimitStateModel

3. Error handling:
   - 404: Repository not found or no access, mark as error
   - 403: Rate limit exceeded, raise RateLimitExceededError
   - 500/502/503: Transient error, retry with backoff

PyGithub conditional request pattern:
```python
# PyGithub doesn't expose ETag directly in iterator mode
# Use raw requests for conditional requests
import requests

headers = {"Authorization": f"token {token}"}
if etag:
    headers["If-None-Match"] = etag

response = requests.get(url, headers=headers)
if response.status_code == 304:
    return [], etag, False  # No changes

new_etag = response.headers.get("ETag")
issues_data = response.json()
```

   - `IssueTransformer` class:
     - `__init__(label_tag_mapping: dict | None = None)`

     - `def transform_to_claim(issue: GitHubIssue) -> dict`:
       - Create Claim dict:
         ```python
         {
             "external_id": f"github-issue-{issue.repository}#{issue.number}",
             "title": issue.title,
             "content": issue.body or "",
             "source_url": issue.html_url,
             "author": issue.user.login,
             "created_at": issue.created_at,
             "updated_at": issue.updated_at,
             "confidence": self._derive_confidence(issue),
             "freshness": self._derive_freshness(issue),
             "tags": self._map_labels_to_tags(issue.labels),
             "metadata": {
                 "platform": "github",
                 "type": "issue",
                 "repository": issue.repository,
                 "issue_number": issue.number,
                 "state": issue.state,
                 "labels": [l.name for l in issue.labels],
                 "assignees": [a.login for a in issue.assignees],
                 "milestone": issue.milestone.title if issue.milestone else None,
                 "comments_count": issue.comments_count,
                 "closed_at": issue.closed_at.isoformat() if issue.closed_at else None,
             },
             "related_claims": [],  # Populated when comments fetched
         }
         ```

     - `def _map_labels_to_tags(labels: list[GitHubLabel]) -> list[str]`:
       - Apply custom mapping if provided: label_tag_mapping.get(label.name)
       - Default: lowercase, replace spaces with hyphens
       - Filter out empty tags
       - Return unique list

     - `def _derive_confidence(issue: GitHubIssue) -> str`:
       - closed + milestone = higher confidence
       - Multiple assignees = higher confidence
       - Return: "unverified" | "single_source" | "cross_validated"

     - `def _derive_freshness(issue: GitHubIssue) -> str`:
       - updated < 30 days = "fresh"
       - updated < 180 days = "stale"
       - else = "rotten"
       - Closed issues are "historical"

     - `def transform_comment_to_claim(comment: GitHubComment, parent_issue: GitHubIssue) -> dict`:
       - Create related Claim:
         ```python
         {
             "external_id": f"github-comment-{parent_issue.repository}#{parent_issue.number}-{comment.id}",
             "title": f"Comment on #{parent_issue.number}: {parent_issue.title[:50]}",
             "content": comment.body,
             "source_url": comment.html_url,
             "author": comment.user.login,
             "created_at": comment.created_at,
             "updated_at": comment.updated_at,
             "confidence": "unverified",
             "metadata": {
                 "platform": "github",
                 "type": "comment",
                 "parent_type": "issue",
                 "parent_number": parent_issue.number,
                 "parent_id": parent_issue.id,
             },
         }
         ```

   - `DiscussionTransformer` class:
     - `def transform_to_claim(discussion: GitHubDiscussion) -> dict`:
       - Similar to Issue but with discussion-specific fields:
         ```python
         {
             "external_id": f"github-discussion-{discussion.repository}#{discussion.number}",

             },
         }
         ```

     - `def transform_comment_to_claim(comment: GitHubComment, parent_discussion: GitHubDiscussion) -> dict`:
