# Roadmap: v2.0 Extended Ingestion & Team Platform

**Milestone:** v2.0
**Status:** Complete
**Shipped:** 2026-04-30

---

## Overview

v2.0 扩展了 Smart Agent Wiki 的知识摄入渠道（视频/音频）并支持团队协作部署模式。

## Features Delivered

### Media Ingestion (Phase 4)
- 视频/音频文件上传和转录 (Whisper)
- 支持 MP4, WebM, MOV, MP3, WAV, M4A, OGG 格式
- 批量转录处理
- 转录预览功能
- 元数据提取 (时长、格式、比特率)

### Team Deployment (Phase 5)
- Docker Compose 一键部署
- PostgreSQL 数据库支持
- Redis 缓存和会话管理
- 多用户注册/登录 (JWT 认证)
- RBAC 权限系统 (Admin/Editor/Viewer)
- 私有和共享知识库
- 审计日志 (Ed25519 签名)

### API Platform (Phase 6)
- RESTful API (CRUD 操作)
- API Key 认证
- 速率限制 (Redis sliding window)
- Webhook 事件推送
- GraphQL 端点
- 批量导入/导出 (JSON, CSV, Markdown, NDJSON)
