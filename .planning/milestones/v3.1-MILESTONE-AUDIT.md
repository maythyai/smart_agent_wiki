## Known Limitations

1. **Notion:** Page-level sync only, block-level sync deferred
2. **Logseq:** Outbound sync only, no plugin development
3. **IM Platforms:** Read-only ingestion, no message sending
4. **GitHub:** Read + webhook only, no PR creation
5. **WeCom:** Webhook only, no full OAuth support
6. **Dashboard:** Polling-based, no real-time WebSocket updates
