### Architecture Highlights

1. **数据库层** — SQLAlchemy 2.0 ORM with async support (asyncpg)
2. **认证系统** — JWT access/refresh tokens + bcrypt passwords
3. **权限系统** — RBAC with Admin/Editor/Viewer roles
4. **审计日志** — Ed25519 cryptographic signing for tamper-proof logs
5. **API 认证** — Dual mode: JWT (users) + API Keys (integrations)
6. **速率限制** — Redis sliding window with per-hour/per-day limits
7. **Webhooks** — HMAC-SHA256 signing, 3-retry backoff, auto-disable after 10 failures
8. **GraphQL** — Strawberry schema with Query/Mutation types

### Deployment Configuration

- `docker-compose.yml` with 4 services: app, postgres, redis, nginx
- Health check endpoints at `/health`
- Volume mounts for persistent data
- Environment-based configuration
