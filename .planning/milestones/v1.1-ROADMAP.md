# Milestone v1.1: Collaboration & Visualization

**Status:** ✅ SHIPPED 2026-04-29
**Phases:** 1-3 (5 phase groups)
**Total Plans:** 19

## Overview

Smart Agent Wiki v1.1 完成了完整的多代理协作和 Web UI 可视化功能。用户现在可以通过 6 个专业化 Agent（Librarian/Writer/Critic/Linker/Scholar/Guardian）进行协作工作流编排，并通过 Web UI 搜索知识库、可视化知识图谱、编辑 Wiki 页面。

## Phases

### Phase 1: Core Data Cycle

**Goal**: Users can create a wiki, ingest documents into a trusted four-layer storage system, and query their knowledge base via CLI with full source provenance
**Depends on**: Nothing (first phase)
**Plans**: 3

Plans:
- [x] 01-01: Foundation: Domain + Write Queue + Storage + CLI Init
- [x] 01-02: Ingestion Engine: Document Parsing + LLM Extraction + Git Provenance
- [x] 01-03: Query Engine: Search + Context Compilation + NL Query + Graph

**Details:**
- 四层存储架构：Vault (不可变原始) → Claims DB (主张) → Wiki (可变综合) → FTS5 Index
- Write Queue Outbox 模式：单入口持久化写入，5 个 idempotent sinks
- PDF 三级降级解析：MinerU → Docling → PyMuPDF
- Markdown 解析：YAML frontmatter + heading hierarchy
- 结构化数据零 LLM 提取：AST 解析代码、schema 解析 JSON/表格
- BM25 + FTS5 全文搜索
- NetworkX 图遍历 (BFS/DFS)
- CLI 命令：`saw init`, `saw ingest`, `saw query`, `saw search`
- 105 tests passing

### Phase 2: Intelligence & Governance

**Goal**: Users can trust the quality of their knowledge base through confidence scoring, contradiction detection, freshness tracking, and learning from usage patterns
**Depends on**: Phase 1
**Plans**: 3

Plans:
- [x] 02-01: Governance Core + Learning Engine - Confidence, freshness, lint, verify, review, FSRS
- [x] 02-02: Advanced Governance - Contradiction detection, blast radius, Ed25519 audit trail
- [x] 02-03: MCP Server + Cross-Cutting - 23 MCP tools, progressive memory, adaptive index

**Details:**
- 4 层置信度体系：Unverified → Single Source → Cross-Validated → Human Verified
- 9 级新鲜度系统 (0-8) + 颜色映射
- 矛盾检测：Temporal/Opinion/Factual + 3 策略自动处理
- Blast Radius 分析：影响评分 0-100
- Ed25519 密码审计收据链
- FSRS 间隔重复调度
- 训练期自适应（前 30 天）
- 认知蒸馏与 SOP 自动提取
- MCP Server 23 个工具（覆盖 ingest/query/govern/learn/collaborate）
- 渐进式记忆深度 L0/L1/L2
- 自适应索引演进：flat → hierarchical → indexed
- Research-on-Miss 自动研究闭环
- CLI 命令：`saw lint`, `saw verify`, `saw conflicts`, `saw audit`, `saw freshness`, `saw review`, `saw mcp`
- 287 tests passing

### Phase 3-01: Multi-Agent Foundation

**Goal**: 6 specialized agents with model routing, A2A protocol, and workflow orchestration
**Depends on**: Phase 2
**Plans**: 2

Plans:
- [x] 03-01-01: Agent Foundation - 6 specialized agents, model routing, A2A protocol
- [x] 03-01-02: Workflow + Policy - YAML workflow parser/executor, Cedar policy engine

**Details:**
- 6 个专业化 Agent：
  - Librarian (Haiku): 索引维护、元数据提取
  - Writer (Sonnet): Wiki 页面创作
  - Critic (Sonnet): 质量审核、置信度评估
  - Linker (Haiku): 交叉链接发现
  - Scholar (Opus): 深度推理、综述生成
  - Guardian (Rule): 零 LLM 安全检查
- 三层模型路由：Opus → Sonnet → Haiku fallback
- A2A 协议：REQUEST/RESPONSE/BROADCAST/HANDOFF 消息类型
- Ed25519 签名收据
- YAML 工作流编排：steps, gates, fallback actions
- Cedar 策略引擎：permit/forbid 按 Agent × Tool 组合
- 默认拒绝策略（fail-secure）
- CollaborateEngine 统一入口
- 143 tests passing
