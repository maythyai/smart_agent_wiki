# 启发式评估参考（Mode B · 代码审查）

> 本文件是各模块审计代理的共享依据。**先读本文件，再开始审查。**
> 评估模式：`mode: heuristic-review`（不伪装成真实用户测试）。

## 评估方法
- 仅基于代码做 Nielsen 10 启发式审查，无需运行项目、无需用户。
- 每条 finding 必须引用**代码证据**（`文件路径:行号`）。
- 每条 finding 标注：违反原则编号（1-10）、严重度（Nielsen 0-4）、置信度（high/medium/low）。
- 关注**用户可用性**：用户能否完成核心任务、状态反馈是否充分、错误是否可恢复、交互是否一致、是否预防错误、是否识别而非回忆、是否灵活高效、是否极简、错误信息是否可懂、是否有帮助。
- 同时关注**核心功能的设计合理性与完成程度**（是否有 stub/TODO/未接线/降级分支/不可达路径）。

## Nielsen 10 原则速查
1. **系统状态可见性**：异步操作是否有 loading/成功/失败/进度反馈；列表是否区分 loading/error/empty/success；按钮提交中是否 disabled；断连是否通知。违反：静默失败、幽灵按钮、薛定谔表单、假死列表。
2. **系统与现实匹配**：错误信息是否用用户语言（非技术堆栈/字段名）；日期货币本地化；图标隐喻；业务术语。违反：技术报错暴露、字段名泄露。
3. **用户控制权与自由度**：破坏性操作二次确认；撤销；中途取消；弹窗 ESC/遮罩/关闭按钮；返回导航；草稿。违反：死亡对话框、不可逆删除、强制流程、劫持后退。
4. **一致性与标准**：同组件跨页一致；术语统一；颜色语义一致；交互模式一致；遵循框架规范；快捷键一致。违反：术语混乱、样式漂移、交互不一致。
5. **错误预防**：实时校验；危险操作确认；输入格式引导；不合理输入限制；搜索防抖；密码强度。违反：延迟报错、无保护危险操作、模糊输入、静默截断。
6. **识别而非回忆**：导航清晰；搜索历史/最近操作；多步表单可见前序；操作上下文可见；错误定位；面包屑；操作时显示名称非 ID。违反：隐藏导航、无上下文表单、神秘编号、记忆型快捷键。
7. **灵活性与效率**：快捷键；批量操作；可跳过引导；自定义；高级搜索语法；命令面板/右键菜单；新手引导可关。违反：只有鼠标路径、逐一操作、强制引导、一刀切。
8. **美学与极简设计**：只展示必要信息；弹窗精简；避免长说明；错误简洁；无"以防万一"按钮；视觉层次；空状态有意义。违反：信息过载、弹窗轰炸、防御性文案、功能膨胀。
9. **帮助识别诊断恢复错误**：错误三段式（发生了什么+为什么+怎么办）；避免错误码；表单错误定位字段；网络错误重试；权限错误指引；建设性语气；全局 fallback。违反：裸错误码、推卸责任、死胡同、技术天书。
10. **帮助与文档**：上下文帮助；空状态引导；首次使用引导；帮助可搜；placeholder/helper text；快捷键查看入口；404 导航帮助。违反：帮助失踪、文档孤岛、技术文档、缺上下文帮助。

## 严重度（Nielsen 0-4）
- **4 catastrophic**：无法完成核心任务/数据丢失，上线前必修。
- **3 critical**：需大量帮助/严重挫败，上线前必修。
- **2 major**：反复出现但能绕过，首版必修。
- **1 minor**：偶发不影响完成。
- **0 cosmetic**：纯视觉细节。
特殊规则：严重度优先于频次；CTA 转化路径上的 cosmetic 不能简单丢 P3；首次印象问题至少 major。

## Mode B 优先级矩阵（severity × confidence）
| severity\confidence | high | medium | low |
|---|---|---|---|
| 4 | P0 | P0 | P1 |
| 3 | P0 | P1 | P1 |
| 2 | P1 | P2 | P2 |
| 1 | P2 | P3 | P3 |
| 0 | P3 | P3 | P3 |

## 红线（必须遵守）
- 不编造证据；找不到证据就不写该 finding。
- 不在评估中为设计辩护。
- `mode: heuristic-review` 必须显式标注；不替代真实用户测试。
- 每条 finding 必须有完整证据链（文件:行号 + 违反点 + 后果）。

## 工作约束
- 使用 `mcp__local__*` 工具访问用户本地项目（根目录 `/Users/cs/projects/smart_agent_wiki`）。**禁止**使用内置 Read/Grep/Bash（在该环境被禁用）。
- 用 `mcp__local__read_file` / `mcp__local__grep` / `mcp__local__glob` / `mcp__local__list_dir` 探查代码。
- 用 `mcp__local__write_file` 把最终报告写入指定路径。
- 真实读取代码后再下结论；行号要准确。
- 审查要全面（覆盖该模块所有关键文件），但报告要精炼（findings 聚焦真问题，不堆砌）。
